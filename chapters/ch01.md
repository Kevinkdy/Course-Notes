## 계량경제학은 무엇을 하는가

### 상관관계와 인과관계

계량경제학의 목표는 대부분 **인과 효과**를 재는 것입니다. "교육을 1년 더 받으면
임금이 얼마나 오르는가", "최저임금을 올리면 고용이 얼마나 줄어드는가" 같은 질문요.

그런데 자료가 우리에게 직접 보여주는 것은 **연관**뿐입니다. 교육을 많이 받은
사람의 임금이 높다는 사실은 관측되지만, 그것이 교육 **때문**인지는 자료에 적혀
있지 않습니다.

> **계량경제학은 연관을 인과로 읽어도 되는 조건을 따지는 학문입니다.**

2장의 $E(u \mid x) = 0$ 부터 15장의 도구변수까지, 전부 이 조건을 확보하려는
시도입니다.

### 자료의 종류

어떤 자료를 다루느냐에 따라 쓸 수 있는 방법이 달라집니다.

| 종류 | 구조 | 예 | 다루는 장 |
|---|---|---|---|
| **횡단면** (cross-section) | 여러 대상을 **한 시점**에 | 2024년 근로자 526명의 임금 | 2–9장 |
| **시계열** (time series) | **한 대상**을 여러 시점에 | 1990–2024년 한국 GDP | 10–12장 |
| **합동 횡단면** (pooled cross-section) | 여러 시점에 **매번 다른** 대상을 | 2020년 표본 + 2024년 표본 | 13장 |
| **패널** (panel) | **같은 대상**을 여러 시점에 | 같은 근로자 500명을 5년간 추적 | 13–14장 |

**합동 횡단면과 패널의 차이가 중요합니다.** 둘 다 "여러 해의 자료"지만, 패널은
같은 사람을 계속 따라갑니다. 그래서 **그 사람의 변하지 않는 특성(타고난 능력 등)을
없앨 수 있습니다.** 14장 고정효과가 그 이야기입니다.

### "다른 조건들이 동일할 때"

경제학에서 어떤 효과를 말할 때는 **나머지를 고정한 채** 하나만 바꿨을 때의 변화를
뜻합니다. 라틴어로 *ceteris paribus* 라고 씁니다.

문제는 현실에서 나머지를 고정할 수 없다는 것입니다. 사람에게 "능력은 그대로 두고
교육만 1년 더 받아라"라고 할 수 없으니까 말입니다. **회귀분석은 그 고정을 계산으로
흉내 내는 도구입니다.** 얼마나 잘 흉내 내는지가 이 과목의 주제입니다.

## 준비물 ①: 선형대수

이 노트에서 쓰는 선형대수는 **다섯 개뿐**입니다. 행렬식, 역행렬, 고유값 같은 것은
쓰지 않습니다.

### 벡터 — 숫자를 한 줄로 묶은 것

근로자 3명의 임금이 각각 10, 14, 12만원이라면, 이것을 하나로 묶어 쓸 수 있습니다.

$$y = (10,\ 14,\ 12)' = \begin{pmatrix} 10 \\ 14 \\ 12 \end{pmatrix}$$

성분 사이에 쉼표를 찍어 구분합니다. 가로로 쓸 때는 $(10,\ 14,\ 12)$ 처럼 쓰고,
오른쪽 위의 프라임 $'$ 은 "세워서 읽으라"는 표시입니다. 계량경제학에서 벡터는
기본적으로 **세로**입니다.

이게 **벡터**입니다. 그냥 숫자 묶음인데, 중요한 것은 이것을 **3차원 공간의 화살표
하나**로 볼 수 있다는 점입니다. 첫 번째 좌표가 10, 두 번째가 14, 세 번째가 12인
지점까지 뻗은 화살표요.

> [!IMPORTANT]
> **여기서 한 번 머리를 바꿔야 합니다**
>
> 산점도에서는 **한 사람이 점 하나**였습니다. 관측치가 3명이면 점이 3개입니다.
>
> 벡터로 보면 **한 변수가 화살표 하나**입니다. 관측치가 3명이면 **3차원 공간**이
> 되고, 임금이라는 변수 전체가 화살표 **한 개**가 됩니다.
>
> 이 전환이 3장의 그림을 읽는 열쇠입니다. 지금 당장 와닿지 않아도 괜찮습니다.
> 3장에서 그림과 함께 다시 설명합니다.

### 선형결합 — 섞기

벡터 여러 개에 각각 숫자를 곱해서 더하는 것입니다.

$$3 x_1 + 2 x_2 \quad \text{예를 들어} \quad
3 \cdot (1,\ 2,\ 0)' + 2 \cdot (0,\ 1,\ 4)' = (3,\ 8,\ 8)'$$

**회귀는 결국 이것입니다.** $\hat y = \hat\beta_1 x_1 + \hat\beta_2 x_2$ 는
"교육 벡터를 $\hat\beta_1$ 만큼, 경력 벡터를 $\hat\beta_2$ 만큼 섞은 것"입니다.
회귀계수는 **섞는 비율**입니다.

### 내적 — 두 벡터가 얼마나 같은 방향인가

같은 자리 원소끼리 곱해서 전부 더합니다.

$$x = (x_1,\ x_2,\ \ldots,\ x_n)', \qquad y = (y_1,\ y_2,\ \ldots,\ y_n)'$$

$$x'y = x_1y_1 + x_2y_2 + \cdots + x_ny_n = \sum_{i=1}^{n} x_i y_i$$

값이 크면 두 벡터가 비슷한 방향, 음수면 반대 방향입니다.

**공분산과 상관계수가 사실 내적입니다.** 평균을 뺀 뒤 내적을 구하면 공분산이
나오고, 길이로 나누면 상관계수가 됩니다. 그래서 "두 변수가 같이 움직인다"와
"두 벡터가 같은 방향이다"는 같은 말입니다.

### 직교 — 내적이 0

$$x'y = 0$$

기하학적으로는 **직각**입니다. 두 벡터가 아무 공통 방향도 갖지 않는 상태입니다.

**OLS의 핵심 성질이 이것입니다.** 잔차는 모든 설명변수와 직교합니다
($X'\hat u = 0$). 3장에서 이게 왜 자동으로 성립하는지 그림으로 봅니다.

### 길이 — 자기 자신과의 내적의 제곱근

$$\|x\| = \sqrt{x'x} = \sqrt{x_1^2 + x_2^2 + \cdots + x_n^2} = \sqrt{\sum_{i=1}^n x_i^2}$$

두 벡터 사이의 **거리**는 차이 벡터의 길이입니다.

$$\|x - y\| = \sqrt{\sum_{i=1}^n (x_i - y_i)^2}$$

그리고 내적·길이·각도는 이렇게 묶입니다.

$$x'y = \|x\|\,\|y\|\cos\theta \qquad \Longrightarrow \qquad \cos\theta = \frac{x'y}{\|x\|\,\|y\|}$$

**이 마지막 식이 상관계수입니다.** 평균을 뺀 두 벡터의 $\cos\theta$ 가 곧
$r$ 이고, 3장에서 $R^2 = \cos^2\theta$ 가 나오는 뿌리도 여기입니다.

피타고라스 정리 그대로입니다. **제곱합이 곧 길이의 제곱**이라는 점을 기억해
두세요. "잔차제곱합을 최소화한다"가 "잔차 벡터의 길이를 최소화한다"와 같은 말이
되는 이유입니다.

### 열공간 — 만들 수 있는 것 전부

$x_1$ 과 $x_2$ 를 **온갖 비율로 섞어서 만들 수 있는 모든 벡터**의 모임입니다.
$\text{col}(X)$ 라고 씁니다.

벡터가 2개면 이 모임은 **평면**이 됩니다. 3장의 회색 평면이 바로 이것입니다.
회귀가 하는 일은 **이 평면 위에서 $y$ 에 가장 가까운 점을 찾는 것**입니다.

## 준비물 ②: 확률과 통계

### 확률변수

값이 미리 정해져 있지 않고, 뽑아 봐야 아는 양입니다. "무작위로 고른 한국인 한 명의
임금"은 확률변수입니다. 누구를 고르느냐에 따라 달라지니까 말입니다.

대문자 $X, Y$ 로 쓰고, 실제로 관측된 값은 소문자 $x_i, y_i$ 로 씁니다. 다만
계량경제학 교재는 이 구분을 느슨하게 하는 편이라, 이 노트도 $y$ 를 양쪽에 씁니다.

### 기댓값 — 무게중심

$$E(X) = \text{확률로 가중평균한 값}$$

분포의 **무게중심**이라고 생각하시면 됩니다. 모집단 전체의 평균이고, 우리가
관측할 수 없는 값입니다.

**이 노트에서 쓰는 성질은 사실상 하나입니다 — 선형성.**

$$E(aX + bY + c) = a\,E(X) + b\,E(Y) + c$$

> [!IMPORTANT]
> **불편성 증명은 이 한 줄이 전부입니다**
>
> 2장에서 "$`\hat\beta_1`$ 이 불편이다"를 증명할 때 하는 일은,
> $\hat\beta_1$ 을 $\beta_1 + (\text{오차 항들의 합})$ 형태로 만든 다음
> 양변에 기댓값을 씌우는 것뿐입니다. 그러면 선형성 덕분에 합과 상수가 밖으로
> 빠져나오고, 오차 부분이 0이 되면서 $E(\hat\beta_1) = \beta_1$ 이 남습니다.
>
> 어려운 것은 계산이 아니라 **어떤 가정이 있어야 그 부분이 0이 되는가**입니다.

### 기댓값의 성질 모음

| | 공식 | 조건 |
|---|---|---|
| 상수 | $E(c) = c$ | |
| 선형성 | $E(aX + b) = a\,E(X) + b$ | 항상 |
| 합 | $E(X + Y) = E(X) + E(Y)$ | **항상** (독립 불필요) |
| 일반형 | $E\!\left(\sum_i a_i X_i + b\right) = \sum_i a_i E(X_i) + b$ | 항상 |
| 곱 | $E(XY) = E(X)E(Y)$ | $X, Y$ 가 **독립일 때만** |

> [!WARNING]
> **합은 항상, 곱은 독립일 때만**
>
> $E(X+Y) = E(X)+E(Y)$ 는 아무 조건 없이 성립합니다. 반면
> $E(XY) = E(X)E(Y)$ 는 독립이어야 합니다. 이 둘을 헷갈리면 증명이 어긋납니다.
>
> 불편성 증명이 쉬운 이유가 **덧셈만 쓰기 때문**입니다.

### 분산 — 얼마나 흩어져 있는가

$$\text{Var}(X) = E\left[(X - E(X))^2\right] = \sigma_X^2, \qquad \text{sd}(X) = \sigma_X = \sqrt{\text{Var}(X)}$$

계산할 때는 아래 형태가 훨씬 편합니다.

$$\boxed{\ \text{Var}(X) = E(X^2) - \left[E(X)\right]^2\ }$$

**성질 모음**

| | 공식 | 조건 |
|---|---|---|
| 상수 | $\text{Var}(c) = 0$ | |
| 평행이동 | $\text{Var}(X + b) = \text{Var}(X)$ | 항상 |
| 척도 | $\text{Var}(aX) = a^2\,\text{Var}(X)$ | 항상 |
| 둘 합침 | $\text{Var}(aX + b) = a^2\,\text{Var}(X)$ | 항상 |
| 합 | $\text{Var}(X + Y) = \text{Var}(X) + \text{Var}(Y) + 2\,\text{Cov}(X,Y)$ | **항상** |
| 차 | $\text{Var}(X - Y) = \text{Var}(X) + \text{Var}(Y) - 2\,\text{Cov}(X,Y)$ | 항상 |
| 일반형 | $\text{Var}(aX + bY) = a^2\text{Var}(X) + b^2\text{Var}(Y) + 2ab\,\text{Cov}(X,Y)$ | 항상 |
| 독립일 때 | $\text{Var}\!\left(\sum_i X_i\right) = \sum_i \text{Var}(X_i)$ | $\text{Cov} = 0$ 일 때 |
| 표본평균 | $\text{Var}(\bar X) = \dfrac{\sigma^2}{n}$ | 독립 · 같은 분산 |

마지막 줄이 **표준오차의 뿌리**입니다. $\text{sd}(\bar X) = \sigma/\sqrt{n}$ 이고,
$\sigma$ 를 $s$ 로 바꾼 것이 $\text{SE}_{\bar x} = s/\sqrt{n}$ 입니다.
자료가 많아질수록 흔들림이 줄어드는 이유가 이 $\sqrt{n}$ 입니다.

### 공분산 — 같이 움직이는가

$$\text{Cov}(X, Y) = E\left[(X - E(X))(Y - E(Y))\right] = \sigma_{XY}$$

역시 계산용 형태가 따로 있습니다.

$$\boxed{\ \text{Cov}(X, Y) = E(XY) - E(X)E(Y)\ }$$

**성질 모음**

| | 공식 | 비고 |
|---|---|---|
| 자기 자신 | $\text{Cov}(X, X) = \text{Var}(X)$ | 분산은 공분산의 특수한 경우 |
| 대칭 | $\text{Cov}(X, Y) = \text{Cov}(Y, X)$ | |
| 상수 | $\text{Cov}(X, c) = 0$ | 상수는 움직이지 않음 |
| 평행이동 | $\text{Cov}(X + a,\ Y + b) = \text{Cov}(X, Y)$ | 위치는 무관 |
| 척도 | $\text{Cov}(aX,\ bY) = ab\,\text{Cov}(X, Y)$ | **단위에 휘둘림** |
| 분배 | $\text{Cov}(X,\ Y + Z) = \text{Cov}(X,Y) + \text{Cov}(X,Z)$ | |
| 일반형 | $\text{Cov}\!\left(a + bX,\ c + dY\right) = bd\,\text{Cov}(X, Y)$ | |
| 독립이면 | $X \perp Y \Rightarrow \text{Cov}(X,Y) = 0$ | **역은 성립하지 않음** |

> [!NOTE]
> **공분산이 0이라고 관계가 없는 것은 아닙니다**
>
> 공분산은 **직선적인** 관계만 잡아냅니다. $Y$ 가 $X$ 의 U자 모양을 따르면,
> 실제로는 강하게 연결되어 있어도 공분산은 0이 나올 수 있습니다.
>
> 즉 **독립 ⟹ 공분산 0** 은 참이지만, **공분산 0 ⟹ 독립** 은 거짓입니다.
>
> 2장에서 $\text{Cov}(x,u)=0$ 보다 $E(u \mid x)=0$ 을 요구하는 이유가 이것입니다.

그리고 2장 유도에서 실제로 쓰는 형태입니다. $y = \beta_0 + \beta_1 x + u$ 일 때

$$\text{Cov}(x, y) = \text{Cov}(x,\ \beta_0 + \beta_1 x + u) = \beta_1 \text{Var}(x) + \text{Cov}(x, u)$$

위 표의 "상수", "척도", "분배"를 차례로 쓴 것뿐입니다.

### 상관계수 — 단위를 없앤 공분산

공분산은 단위에 휘둘립니다. 임금을 원으로 재느냐 만원으로 재느냐에 따라 값이
1만 배 달라집니다 (위 표의 "척도" 줄). 그래서 단위를 없앤 것이 상관계수입니다.

$$\rho_{XY} = \frac{\text{Cov}(X,Y)}{\sqrt{\text{Var}(X)}\sqrt{\text{Var}(Y)}} = \frac{\sigma_{XY}}{\sigma_X \sigma_Y}, \qquad -1 \le \rho_{XY} \le 1$$

| | 공식 | 비고 |
|---|---|---|
| 단위 무관 | $\rho_{aX+b,\ cY+d} = \rho_{XY}$ | $a, c > 0$ 일 때 |
| 완전한 직선 | $Y = a + bX \Rightarrow \rho = \pm 1$ | $b$ 의 부호를 따름 |
| 기울기와의 관계 | $\beta_1 = \rho_{XY} \cdot \dfrac{\sigma_Y}{\sigma_X}$ | 2장에서 다시 나옴 |

마지막 줄을 기억해 두세요. **기울기는 상관계수에 단위 환산을 곱한 것**입니다.
상관계수는 단위가 없고 기울기는 단위가 있는데, 둘의 차이는 그것뿐입니다.

### 조건부 기댓값 — 계량경제학의 심장

$$E(Y \mid X = x) = \text{$X$ 가 $x$ 인 사람들만 모았을 때의 $Y$ 평균}$$

"교육연수가 12년인 사람들의 평균 임금"이 조건부 기댓값입니다.

**회귀가 추정하려는 대상이 바로 이것입니다.** 모집단 회귀함수
$E(y \mid x) = \beta_0 + \beta_1 x$ 는 "$`x`$ 가 주어졌을 때 $`y`$ 의 평균이 이렇게
생겼다"는 주장입니다.

**성질 모음**

| | 공식 | 말로 하면 |
|---|---|---|
| 선형성 | $E(aY + bZ + c \mid X) = a E(Y\mid X) + b E(Z \mid X) + c$ | 기댓값과 같음 |
| 빼내기 | $E\!\left[g(X)\,Y \mid X\right] = g(X)\,E(Y \mid X)$ | $X$ 를 고정했으니 $g(X)$ 는 상수 |
| 독립 | $X \perp Y \Rightarrow E(Y \mid X) = E(Y)$ | $X$ 를 알아도 도움이 안 됨 |
| 반복 기댓값 | $E\!\left[E(Y \mid X)\right] = E(Y)$ | 집단별 평균의 평균 = 전체 평균 |
| 총분산 | $\text{Var}(Y) = E\!\left[\text{Var}(Y\mid X)\right] + \text{Var}\!\left[E(Y\mid X)\right]$ | 집단 안의 흩어짐 + 집단 간의 흩어짐 |

두 번째 **빼내기**와 네 번째 **반복 기댓값**이 2장 불편성 증명에서 쓰입니다.

**반복 기댓값의 법칙 (Law of Iterated Expectations)**

$$E\left[E(Y \mid X)\right] = E(Y)$$

말로 하면 이렇습니다 — **집단별 평균을 다시 평균내면 전체 평균이 된다.**
교육연수별 평균 임금을 구한 뒤, 그것들을 (인원수로 가중해서) 평균내면 전체 평균
임금이 나옵니다. 당연한 이야기입니다.

> [!TIP]
> **이 법칙이 바로 쓰이는 곳**
>
> 2장의 가정 $E(u \mid x) = 0$ 에서 두 가지가 따라 나옵니다.
>
> **① 오차의 전체 평균도 0이다**
>
> $$E(u) = E\left[E(u \mid x)\right] = E[0] = 0$$
>
> **② $x$ 와 $u$ 의 공분산도 0이다**
>
> $$\text{Cov}(x, u) = E(xu) = E\left[E(xu \mid x)\right] = E\left[x \cdot E(u \mid x)\right] = E[x \cdot 0] = 0$$
>
> 즉 **$E(u\mid x)=0$ 하나가 나머지 둘을 자동으로 포함합니다.** 그래서 이것이
> 가장 강한 가정입니다. 2장에서 이 셋을 구분하는 이유가 여기 있습니다.

### 모집단과 표본, 그리고 추정량

- **모수(parameter)** — 모집단의 진짜 값. $\beta_1$, $\sigma^2$ 처럼 씁니다.
  **고정된 숫자이고, 우리는 모릅니다.**
- **추정량(estimator)** — 자료로 모수를 맞히려고 만든 계산 공식. $\hat\beta_1$.
  **자료에 따라 값이 달라지므로 확률변수입니다.**
- **추정값(estimate)** — 우리 표본에 그 공식을 넣어 나온 구체적 숫자. 0.083 같은 것.

이 셋을 섞어 쓰면 4장부터 말이 안 통합니다. **모자(hat)가 붙어 있으면 자료에서
계산한 것**이라고 기억하시면 됩니다.

### 추정량을 평가하는 두 가지 기준

추정량은 공식일 뿐이라 좋은 것도 나쁜 것도 만들 수 있습니다. 그래서 기준이
필요합니다.

**불편성 (unbiasedness) — 평균적으로 맞는가**

$$E(\hat\beta_1) = \beta_1$$

표본을 무수히 많이 뽑아 매번 $\hat\beta_1$ 을 계산했을 때, **그 값들의 평균이
진짜 $\beta_1$ 과 같다**는 뜻입니다.

한 번 뽑은 우리 표본에서 맞는다는 말이 **아닙니다.** 개별 추정값은 얼마든지
빗나갈 수 있습니다. 체계적으로 한쪽으로 치우치지 않는다는 뜻일 뿐입니다.

**일치성 (consistency) — 자료가 많아지면 가까워지는가**

$$\hat\beta_1 \xrightarrow{\ p\ } \beta_1 \quad (n \to \infty)$$

표본 크기를 키우면 $\hat\beta_1$ 이 $\beta_1$ 로 수렴한다는 뜻입니다.

> [!NOTE]
> **둘은 다른 이야기입니다**
>
> - 불편이지만 일치가 아닌 추정량, 일치지만 불편이 아닌 추정량이 모두 존재합니다.
> - **불편성**은 표본 크기와 무관하게 성립하는 성질입니다 (유한표본 성질).
> - **일치성**은 $n$ 이 커질 때의 이야기입니다 (점근적 성질).
>
> 2장·3장에서는 불편성을, 5장에서는 일치성을 다룹니다. 실무에서는 불편성이
> 깨져도 일치성만 있으면 쓰는 경우가 많습니다.

## 준비물 ③: 표본에서 계산하는 것들

앞의 공식들은 전부 **모집단**에 대한 것이라 실제로 계산할 수 없습니다. 자료로
계산하는 대응물이 따로 있습니다.

### 표본 통계량

| 모집단 | 표본 | 공식 |
|---|---|---|
| $E(X) = \mu$ | $\bar x$ | $\bar x = \dfrac{1}{n}\sum_{i=1}^n x_i$ |
| $\text{Var}(X) = \sigma^2$ | $s_x^2$ | $s_x^2 = \dfrac{1}{n-1}\sum (x_i - \bar x)^2$ |
| $\text{sd}(X) = \sigma$ | $s_x$ | $s_x = \sqrt{s_x^2}$ |
| $\text{Cov}(X,Y) = \sigma_{XY}$ | $s_{xy}$ | $s_{xy} = \dfrac{1}{n-1}\sum (x_i - \bar x)(y_i - \bar y)$ |
| $\rho_{XY}$ | $r$ | $r = \dfrac{s_{xy}}{s_x s_y} = \dfrac{1}{n-1}\sum\left(\dfrac{x_i - \bar x}{s_x}\right)\left(\dfrac{y_i - \bar y}{s_y}\right)$ |

> [!NOTE]
> **왜 $n$ 이 아니라 $n-1$ 로 나누는가**
>
> $\bar x$ 를 이미 자료에서 뽑아 썼기 때문입니다. 편차 $(x_i - \bar x)$ 들은
> 합이 0이라는 제약을 하나 받고 있어서, 자유롭게 움직이는 것은 $n$ 개가 아니라
> $n-1$ 개입니다. 이것이 **자유도**이고, $n-1$ 로 나눠야 $E(s_x^2) = \sigma^2$
> 이 됩니다.
>
> 회귀에서 모수를 $k+1$ 개 추정하면 같은 논리로 $n-k-1$ 이 됩니다.

### 유도에 쓰는 대수 항등식

2장·3장에서 계산할 때 반복해서 나옵니다. 외울 필요는 없지만 보면 알아보셔야
합니다.

$$\sum_{i=1}^n (x_i - \bar x) = 0$$

$$\sum (x_i - \bar x)^2 = \sum x_i^2 - n\bar x^2$$

$$\sum (x_i - \bar x)(y_i - \bar y) = \sum (x_i - \bar x)\,y_i = \sum x_i y_i - n\bar x \bar y$$

가운데 식이 특히 유용합니다 — **한쪽만 평균을 빼도 결과가 같습니다.** 첫 번째
식 때문입니다.

## 준비물 ④: 통계학 수업에서 배운 공식들

통계학 입문에서 배운 것들이 계량경제학에서 이름만 바꿔 다시 나옵니다. 어느 것이
어느 것인지 짚어두겠습니다.

> [!WARNING]
> **공식 카드를 볼 때 기호를 바꿔 읽으세요**
>
> 통계학 수업의 공식 카드는 제곱합을 **SST = SSM + SSE** 로 씁니다
> (Total = Model + Error). **이 노트는 Wooldridge 표기만 씁니다.**
>
> | 무엇의 제곱합인가 | 통계학 수업 | **이 노트 (Wooldridge)** |
> |---|---|---|
> | 총변동 | SST | **SST** |
> | 설명된 변동 | SSM (Model) | **SSE** (Explained) |
> | 잔차 변동 | SSE (Error) | **SSR** (Residuals) |
>
> **통계학 수업의 SSE 는 잔차**이고, **이 노트의 SSE 는 설명된 변동**입니다.
> 아래 공식은 전부 오른쪽(Wooldridge) 표기로 적었습니다. 공식 카드를 나란히
> 놓고 볼 때는 이 대응을 거쳐서 읽으세요.

### 표준화와 표본평균의 분포

$$z = \frac{x - \mu}{\sigma}, \qquad z = \frac{\bar x - \mu}{\sigma/\sqrt{n}}, \qquad \text{SE}_{\bar x} = \frac{s}{\sqrt{n}}$$

$\sigma$ 를 아는 경우는 현실에 거의 없으므로, $s$ 로 바꾸고 $t$ 분포를 씁니다.

### 신뢰구간과 검정 (한 표본)

| 상황 | 공식 | 자유도 |
|---|---|---|
| $\mu$ 신뢰구간 ($\sigma$ 알 때) | $\bar x \pm z^{*}\dfrac{\sigma}{\sqrt n}$ | — |
| $\mu$ 신뢰구간 ($\sigma$ 모를 때) | $\bar x \pm t^{*}\dfrac{s}{\sqrt n}$ | $n-1$ |
| $H_0: \mu = \mu_0$ 검정 | $t = \dfrac{\bar x - \mu_0}{s/\sqrt n}$ | $n-1$ |

$z^{*}$ 값: 90%는 1.645, 95%는 1.960, 99%는 2.576.

**이 형태를 기억해 두세요.** 4장에서 회귀계수를 검정할 때도 똑같습니다 —
$(\text{추정값} - \text{가설값}) / \text{표준오차}$.

### 단순회귀 (통계학 수업의 표기)

통계학 수업에서는 $y_i = \beta_0 + \beta_1 x_i + \epsilon_i$ 를 놓고
$b_0, b_1$ 로 추정합니다. **Wooldridge 의 $\hat\beta_0, \hat\beta_1$ 과 같은
것입니다.**

$$b_1 = r\,\frac{s_y}{s_x}, \qquad b_0 = \bar y - b_1 \bar x$$

앞에서 본 $\beta_1 = \rho \cdot \sigma_Y/\sigma_X$ 의 표본 버전입니다.

**오차분산의 추정**

$$\hat\sigma^2 = \frac{1}{n-2}\sum_{i=1}^n \hat u_i^2 = \frac{\text{SSR}}{n-2}, \qquad \hat u_i = y_i - \hat y_i$$

공식 카드에서는 이것을 $s^2 = \text{SSE}/(n-2)$ 라고 적습니다 — 같은 것입니다.
**$n-2$ 인 이유는
$\beta_0, \beta_1$ 두 개를 추정했기 때문**이고, 설명변수가 $k$ 개인 다중회귀에서는
$n-k-1$ 이 됩니다.

**표준오차**

$$\text{SE}(\hat\beta_1) = \frac{\hat\sigma}{\sqrt{\sum (x_i - \bar x)^2}}, \qquad
\text{SE}(\hat\beta_0) = \hat\sigma\sqrt{\frac{1}{n} + \frac{\bar x^2}{\sum (x_i - \bar x)^2}}$$

> [!IMPORTANT]
> **$\text{SE}(\hat\beta_1)$ 을 들여다보세요**
>
> 분모에 $\sum (x_i - \bar x)^2$, 즉 **$x$ 의 변동**이 들어 있습니다.
>
> - $x$ 가 많이 변할수록 → 분모가 커짐 → **표준오차가 작아짐** → 추정이 안정적
> - $x$ 가 거의 안 변하면 → 분모가 작아짐 → **표준오차가 폭발**
>
> 2장에서 "$`x`$ 의 변동이 작으면 추정이 불안정하다"고 한 것이 이 식입니다.
> 3장의 다중공선성, 15장의 약한 도구변수도 전부 이 분모가 작아지는 이야기입니다.

**검정과 신뢰구간**

$$t = \frac{\hat\beta_1}{\text{SE}(\hat\beta_1)}\ \ (H_0: \beta_1 = 0), \qquad
\hat\beta_1 \pm t^{*}\,\text{SE}(\hat\beta_1), \qquad \text{df} = n - 2$$

회귀 출력의 `t` 열과 `p-value` 열이 바로 이것입니다.

### 예측: 평균을 맞힐 때와 개인을 맞힐 때

$x = x^{*}$ 인 경우의 예측입니다. 두 가지를 구분해야 합니다.

| 무엇을 맞히나 | 추정 | 표준오차 |
|---|---|---|
| **평균 반응** $E(y \mid x^{*})$ | $\hat\beta_0 + \hat\beta_1 x^{*}$ | $\hat\sigma\sqrt{\dfrac{1}{n} + \dfrac{(x^{*}-\bar x)^2}{\sum (x_i - \bar x)^2}}$ |
| **개별 관측치** $y$ | $\hat\beta_0 + \hat\beta_1 x^{*}$ | $\hat\sigma\sqrt{1 + \dfrac{1}{n} + \dfrac{(x^{*}-\bar x)^2}{\sum (x_i - \bar x)^2}}$ |

추정값은 **같은데 표준오차가 다릅니다.** 개별 관측치 쪽에 $1 +$ 이 붙어 있습니다.

이유는 이렇습니다. 평균을 맞힐 때는 **선의 위치만** 틀리면 됩니다. 그런데 개인을
맞힐 때는 선의 위치 오차에 더해 **그 사람의 $u$ 까지** 맞혀야 합니다. $u$ 는
아무리 자료가 많아져도 사라지지 않으므로, 예측구간은 표본이 커져도 일정 이상
좁아지지 않습니다.

> 신뢰구간(confidence interval)은 **평균**에 대한 것이고,
> 예측구간(prediction interval)은 **개인**에 대한 것입니다. 항상 예측구간이 넓습니다.

### 제곱합 분해와 자유도

$$\text{SST} = \underbrace{\sum (y_i - \bar y)^2}_{\text{총변동}}, \quad
\text{SSE} = \underbrace{\sum (\hat y_i - \bar y)^2}_{\text{설명된 변동}}, \quad
\text{SSR} = \underbrace{\sum (y_i - \hat y_i)^2}_{\text{잔차 변동}}$$

$$\text{SST} = \text{SSE} + \text{SSR}, \qquad R^2 = \frac{\text{SSE}}{\text{SST}} = 1 - \frac{\text{SSR}}{\text{SST}}$$

**자유도**

설명변수가 $k$ 개일 때입니다 (상수항 제외).

| | 자유도 | 단순회귀 ($k=1$) |
|---|---|---|
| 총 | $n-1$ | $n-1$ |
| 설명된 부분 | $k$ | $1$ |
| 잔차 | $n-k-1$ | $n-2$ |

### 평균제곱 — 제곱합을 자유도로 나누는 이유

제곱합끼리 바로 비교하면 안 됩니다. **더한 항의 개수가 다르기 때문**입니다.

설명변수를 늘리면 SSE(설명된 변동)는 항상 커집니다. 항이 늘어나니 당연합니다.
그러니 "SSE가 SSR보다 크다"는 사실만으로는 아무것도 말할 수 없습니다. 공정하게
비교하려면 **자유도 하나당 얼마인지**로 환산해야 합니다. 그것이 **평균제곱**입니다.

$$\text{평균제곱} = \frac{\text{제곱합}}{\text{자유도}}$$

회귀에서 쓰는 두 개는 이렇습니다.

| | 이 노트 (Wooldridge) | 통계학 수업 | 뜻 |
|---|---|---|---|
| 잔차 쪽 | $\dfrac{\text{SSR}}{n-k-1} = \hat\sigma^2$ | **MSE** (Mean Square Error) | 설명하지 못하고 남은 변동, 자유도당 |
| 설명된 쪽 | $\dfrac{\text{SSE}}{k}$ | **MSM** (Mean Square Model) | 설명변수들이 잡아낸 변동, 자유도당 |

> [!IMPORTANT]
> **잔차 쪽 평균제곱이 곧 $\hat\sigma^2$ 입니다**
>
> $\text{SSR}/(n-k-1)$ 은 단순히 F 를 만들기 위한 중간 계산이 아닙니다.
> **오차분산 $\sigma^2$ 의 추정값**이고, 모든 표준오차가 여기서 나옵니다.
> 통계학 수업에서 MSE 라고 부르던 것, $s^2$ 이라고 쓰던 것이 전부 같습니다.
>
> $$\hat\sigma = \sqrt{\hat\sigma^2} = \sqrt{\frac{\text{SSR}}{n-k-1}}$$
>
> 회귀 출력에서 `Root MSE`(Stata) 또는 `Residual standard error`(R)로 찍히는
> 값이 이것입니다.

### F 검정 — 두 평균제곱의 비율

$$F = \frac{\text{SSE}/k}{\text{SSR}/(n-k-1)} = \frac{\text{설명된 쪽 평균제곱}}{\text{잔차 쪽 평균제곱}}, \qquad \text{df} = (k,\ n-k-1)$$

통계학 수업 표기로는 $F = \text{MSM}/\text{MSE}$ 입니다. **같은 식입니다.**

**왜 이 비율이 검정이 되는가**

귀무가설은 $H_0: \beta_1 = \cdots = \beta_k = 0$, 즉 **"설명변수 전부가
무의미하다"** 입니다.

- **분모**는 귀무가설이 맞든 틀리든 늘 $\sigma^2$ 근처의 값입니다. 잔차가 만드는
  잡음의 크기니까요.
- **분자**는 사정이 다릅니다.
  - $H_0$ 가 **참**이면, 설명변수가 잡아낸 변동은 순전히 우연입니다. 그래서
    분자도 $\sigma^2$ 근처가 됩니다.
  - $H_0$ 가 **거짓**이면, 진짜 신호가 섞여 들어와 분자가 **커집니다.**

그러니 두 값을 나눠보면 됩니다.

$$F \approx 1 \ \Rightarrow\ \text{설명변수들이 잡아낸 것이 잡음 수준}, \qquad
F \gg 1 \ \Rightarrow\ \text{잡음으로 보기엔 너무 큼}$$

**"신호를 잡음으로 나눈 것"** 이라고 생각하시면 됩니다. 제곱합의 비율이라
$F \ge 0$ 이고, 한쪽 꼬리만 봅니다. $F$ 가 작다고 기각하는 일은 없습니다.

**$R^2$ 로 다시 쓰기**

분자·분모를 SST로 나누면 $R^2$ 만으로 표현됩니다.

$$F = \frac{R^2 / k}{(1 - R^2)/(n - k - 1)}$$

$R^2$ 가 클수록, 그리고 표본이 클수록 $F$ 가 커진다는 것이 한눈에 보입니다.
**$R^2$ 가 작아도 $n$ 이 크면 $F$ 는 유의하게 나올 수 있습니다.** 4장에서
"통계적 유의성 ≠ 경제적 유의성"을 이야기할 때 다시 나오는 지점입니다.

> [!NOTE]
> **단순회귀에서는 $F = t^2$ 입니다**
>
> 설명변수가 하나뿐이면 ($k = 1$) $H_0: \beta_1 = 0$ 을 t 검정으로도, F 검정으로도
> 할 수 있습니다. 그리고 두 결과는 **항상 일치합니다** — $F = t^2$ 이기 때문입니다.
>
> F 가 따로 필요해지는 것은 **여러 계수를 한꺼번에** 검정할 때입니다. t 검정을
> 여러 번 반복하는 것으로는 대신할 수 없습니다. 4장에서 다룹니다.

> [!NOTE]
> **설명변수 개수 표기**
>
> 통계학 교재는 설명변수 개수를 $p$ 로 쓰고 $n - p - 1$ 이라고 적습니다.
> Wooldridge 는 $k$ 를 씁니다. 둘 다 상수항을 빼고 센 개수이므로
> $n - p - 1$ 과 $n - k - 1$ 은 같습니다.

### 그 밖의 공식들

이 과목에서 직접 쓰지는 않지만, 통계학 수업에서 배운 것들입니다. 7장(더미변수)과
16장 이후에서 개념적으로 연결됩니다.

**두 표본 비교**

$$t = \frac{\bar x_1 - \bar x_2}{\sqrt{\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}}}, \qquad
s_p^2 = \frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1 + n_2 - 2}$$

등분산을 가정하면 $s_p$ 를 써서 $\text{df} = n_1 + n_2 - 2$ 가 됩니다.

> 두 집단의 평균 비교는 **더미변수 하나를 넣은 회귀와 같습니다.** 7장에서 이
> 사실을 확인합니다.

**비율**

$$\hat p = \frac{X}{n}, \qquad \text{SE}_{\hat p} = \sqrt{\frac{\hat p(1-\hat p)}{n}}, \qquad
z = \frac{\hat p - p_0}{\sqrt{p_0(1-p_0)/n}}$$

> 종속변수가 0 또는 1 인 경우입니다. 7장의 선형확률모형, 17장의 로짓·프로빗으로
> 이어집니다.

**카이제곱 (분할표)**

$$X^2 = \sum \frac{(\text{관측} - \text{기대})^2}{\text{기대}}, \qquad
\text{df} = (\text{행} - 1)(\text{열} - 1)$$

**일원배치 분산분석**

$$F = \frac{\text{집단 간 제곱합}/(I-1)}{\text{집단 내 제곱합}/(N-I)}, \qquad \text{df} = (I-1,\ N-I)$$

> 집단이 $I$ 개인 평균 비교입니다. **더미변수 $I-1$ 개를 넣은 회귀의 $F$ 검정과
> 같습니다.** 7장에서 다룹니다.

## 표기 약속

이 노트 전체에서 쓰는 대응입니다. 헷갈릴 때 여기로 돌아오세요.

| 모집단 (모름) | 표본 (계산 가능) | 뜻 |
|---|---|---|
| $\beta_0, \beta_1$ | $\hat\beta_0, \hat\beta_1$ | 절편과 기울기 |
| $E(y \mid x) = \beta_0 + \beta_1 x$ | $\hat y = \hat\beta_0 + \hat\beta_1 x$ | 회귀함수 / 회귀선 |
| $u$ | $\hat u$ | 오차 / 잔차 |
| $\sigma^2 = \text{Var}(u)$ | $\hat\sigma^2$ | 오차의 분산 |

기호에 **모자가 붙어 있으면 자료에서 계산한 것**, 없으면 **세상의 진짜 값**입니다.

그리고 제곱합 표기는 교재마다 다릅니다. 이 노트는 Wooldridge 7판을 따릅니다 —
자세한 내용은 [들어가며](../index.md)의 「표기 규약」을 보세요.
